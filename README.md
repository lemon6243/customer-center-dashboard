# 🏢 도시가스 고객센터 성과 대시보드

도시가스 고객센터의 월별 KPI, 반기 마감 전망, 위험센터 개선 우선순위를 분석하는 Streamlit 기반 대시보드입니다.

## ✨ 주요 기능

- 📊 **홈 대시보드**
  - 전체 평균, 센터 순위, 인사이트, 점수 분포 및 추이
  - 반기 진행월에는 현재 누적점수 대신 **반기말 예측점수** 중심으로 해석

- 📈 **성과 분석**
  - 월별 KPI 및 센터 성과 분석
  - 누적형 KPI의 반기 진행률 기반 반기말 점수 예측

- 🎯 **센터 진단**
  - 센터별 KPI 상세 현황 및 반기말 예측 순위
  - KPI 조정 시뮬레이션을 통한 911점 달성 가능성 확인

- ⚠️ **위험 관리**
  - 진행월: 반기말 예측점수 기준 관리
    - 안전: 911점 이상 예상
    - 주의: 895~910점 예상
    - 위험: 895점 미만 예상
  - 마감월(6월·12월): 실제 최종점수 기준 결과 관리

- 🌡️ **KPI 히트맵**
  - 센터별 KPI 성과를 한눈에 비교

- 🔬 **심화 분석 / 상반기 보고**
  - 센터별·KPI별 상세 분석 및 보고 자료 확인

## 📅 반기 평가 기준

| 구분 | 기준 |
|---|---|
| 상반기 | 1~6월, 1,000점 만점 |
| 하반기 | 7~12월, 1,000점 만점 |
| 반기 목표 | 911점 |
| 반기 시작월 | 1월·7월은 누적점수 0점부터 재시작 |
| 진행월 판정 | 현재점수가 아닌 반기말 예측점수 기준 |
| 반기 마감월 | 6월·12월은 실제 최종점수 기준 |
| 비교 기준 | 1월·7월은 전년 동월, 그 외는 같은 반기 전월 |

> 전년 총점 비교는 평가항목·배점 변경 가능성이 있으므로 참고용으로 활용합니다.
